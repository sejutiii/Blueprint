UI layer
Extension «module» extension.ts

Responsibilities

  • Register commands, sidebar views and the status bar
  • Open webview panels and relay their messages to the Orchestrator
  • Set up the LLM provider and validate API keys in the setup wizard
  • Offer a review when new files are created
  • Watch ARCH.md, the ADR index and roles.json, and refresh the UI

BlueprintPanel

Responsibilities

  • Keep one webview panel per type (Setup, Review, Pre-Check, Add Decision, Viewer…)
  • Load panel HTML with a CSP nonce
  • Pass messages between webview and host

StatusBarManager

Responsibilities

  • Show state: not initialized, idle, checking, OK, violation
  • Show pending-approval count and your role
  • Bind the click to the right command

AdrTreeProvider

Responsibilities

  • Filter ADRs by text
  • Show Approve / Reject to Architects

Coordination
Orchestrator

Responsibilities

  • Route events (project init, prompt submitted, code changed, manual review) to agent pipelines
  • Run compliance Pass 1 and Pass 2 in parallel
  • Resolve violations, confirm extensions, draft and save decisions
  • Generate and regenerate ARCH.md
  • Enforce Architect-only actions; read and save roles
  • Report workflow state to the UI

DecisionService

Responsibilities

  • Single entry point for every new ADR
  • Accept an Architect's decision immediately; queue a Developer's for approval
  • Approve or reject pending ADRs (rejection needs a reason)
  • On acceptance: patch ARCH.md, retire the ADR it supersedes, cache its embedding, write the audit trail

Agents
ArchitectureAgent

Responsibilities

  • Generate the architecture blueprint from a system description
  • Regenerate it from a codebase snapshot, keeping every constraint
  • Validate the LLM's JSON

Collaborators

  • LLMClient
ConstraintElicitationAgent

Responsibilities

  • Turn a wizard answer into a draft ADR and one follow-up question
  • Draft an ADR from a free-text decision
  • Suggest which ADR it supersedes; flag tentative input

Collaborators

  • LLMClient
  • ElicitationSession
ElicitationSession

Responsibilities

  • Track the wizard's five topics and their follow-ups (one level deep)
  • Record answers; advance or skip

Collaborators

  • none
ComplianceAgent

Responsibilities

  • Pass 1: find violations of constraints and ADRs in a change
  • Pass 2: find new components missing from ARCH.md (max 5)
  • Fall back to safe defaults on unparseable output

Collaborators

  • LLMClient
PreCheckAgent

Responsibilities

  • Check a coding prompt's intent against constraints and ADRs before code exists
  • Suggest a revised prompt when it conflicts

Collaborators

  • LLMClient
RetrievalAgent

Responsibilities

  • Rank accepted ADRs by relevance (TF-IDF + local embeddings, component boost)
  • Build a search query from a diff summary
  • Cache ADR embeddings

Collaborators

  • EmbeddingService
  • AdrStore
DiffSummarizer

Responsibilities

  • Collect uncommitted changes (git diff HEAD + untracked files)
  • Skip lockfiles and BluePrint's own files
  • Classify files added / modified / renamed / deleted; find added and removed dependencies
  • Extract new imports and declarations; build a diff excerpt

Collaborators

  • TreeSitterExtractor
Infrastructure
LLMClient

Responsibilities

  • Send prompts to Gemini, Groq, OpenRouter, Anthropic or OpenAI
  • Time out and retry on rate limits / server errors
  • Validate and securely store the API key
  • Pick the model (setting or default)

Collaborators

  • external LLM APIs
EmbeddingService

Responsibilities

  • Compute sentence embeddings locally (MiniLM)
  • Download the model on first use
  • Report failure so retrieval falls back to TF-IDF

Collaborators

  • none
TreeSitterExtractor «module»

Collaborators

  • none
CodebaseSnapshot «module»

Responsibilities

AdrStore

Responsibilities

  • Persist ADRs (adr-index.json + docs/adr/*.md)
  • Assign sequential IDs; serialize writes
  • Update ADRs, renaming files on title change
  • Store embeddings

Collaborators

  • none
FileStore

Responsibilities

  • Read and write ARCH.md and arch.json
  • Apply targeted patches (add component, add or replace constraint) that keep manual edits
  • Snapshot history; revert

Collaborators

  • none
AuditLog

Responsibilities

  • Append audit events (reviews, pre-checks, decisions, ARCH.md and role changes)
  • Notify listeners on every append

Collaborators

  • none
AccessControl

Responsibilities

  • Identify the user from git user.email
  • Read and write roles.json
  • Resolve Architect or Developer

Collaborators

  • none
Collaborators are the classes each one calls directly. «module» marks a file of functions rather than a class. Webview pages (HTML) are not shown.
